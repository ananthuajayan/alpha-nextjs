Reindexing a legacy archive, batch by batch.

Client

Sector

Status

Client context

The client is a flooring distribution business with a legacy box archive. Its team already relied on a folder structure to find things.

The manual process and its cost

The archive needed reindexing. The job was too large to run in one go, and doing it by hand would have been slow, repetitive work. Whatever we produced had to fit the folder structure the business already used.

What we built

  • An AI reindexing pipeline for the legacy box archive
  • Checkpoint and resume logic, so multi-batch runs survive interruption
  • Output that mirrors the client's folder structure exactly
